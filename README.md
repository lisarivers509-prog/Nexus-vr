🪐 NexusVR — Next-Gen Remote VR & Desktop SyncNexusVR is an ultra-lightweight, single-file WebVR Remote Desktop hub designed to run seamlessly on low-spec "potato" PCs, integrated GPUs, and standalone VR headsets (Meta Quest, Pico, HTC Vive, PCVR). It enables low-latency desktop streaming, dynamic resolution downscaling, stereoscopic side-by-side (SBS) VR rendering, and direct WebXR headset pairing.✨ Features & Capabilities🥔 Potato PC Optimization EngineDynamic Resolution Downscaling: Instantly switch between 0.5x Eco mode, 0.75x Balanced mode, and 1.0x Native scale to fit weak integrated GPUs.FPS Frame Rate Target Capping: Toggle between 30 FPS, 60 FPS, and 90 FPS to preserve host CPU/GPU cycles.Low-Latency Hardware Codecs: Hardware H.264 (AVC) encoding for fast decode on low-end hardware, with optional HEVC (H.265) and AV1 support.Configurable Bitrate Limit: Fine-tune stream bitrate from 1 Mbps (low Wi-Fi bandwidth) up to 100 Mbps (Ethernet).🥽 Virtual Desktop & WebXR CompatibilityStereoscopic SBS (Side-by-Side) Mode: Native dual-lens rendering for mobile VR headsets, Google Cardboard, or standalone VR Web Browsers.Interactive Geometry Controls: Adjust screen curvature (0°–60°), virtual distance (1.0m–5.0m), and overall display scale.In-VR Quick Connect Overlay: Enter 6-digit VR PIN codes directly within the WebXR 3D space to pair standalone headsets without taking off the headgear.Custom VR Environments: Choose between Void, Studio, Cyber Cinema, and Passthrough Grid environments.📊 Real-Time Stream Telemetry & System DiagnosticsSystem Diagnostic Benchmark: Tests WebGL2 acceleration, WebXR API availability, GPU render-loop stability, WebRTC network latency, and video decoder capability.Live Telemetry Dashboard: Integrated Chart.js graphs displaying real-time stream FPS, decode/network latency (target <15ms), host CPU usage, and GPU encoder load.6DOF Motion Controller Raycasting: Emulate controller laser pointers and head-gyro orientation directly on the virtual desktop canvas.🚀 Quick Start GuidePrerequisitesAny modern web browser supporting HTML5 Canvas, WebGL2, and WebRTC (Chrome, Edge, Brave, Firefox, or Meta Quest Browser).No external server installation required for basic standalone emulation.Running LocallyDownload or clone index.html.Open index.html directly in your browser.Click "Run System Test" in the top navigation bar to run an automatic diagnostic benchmark.Click "Apply Profile & Close" to auto-apply optimal performance settings based on your hardware capabilities.🎮 How to Connect a Standalone VR Headset (Meta Quest / Pico)Host PC: Open NexusVR (index.html) on your host computer.VR Headset: Open the VR browser on your headset (e.g., Meta Quest Browser) and navigate to the hosted NexusVR URL.Select Mode: Click "Headset SBS Mode" or enter full-screen WebXR mode.Pair: Note the 6-digit PIN code on your host display (e.g., 748-291) and enter it using the In-VR keypad overlay.🛠 Performance Presets GuideModeRes ScaleTarget
